# Финансовый Контроль

Offline-first personal finance app. Amounts are stored as integer cents.

## Данные никуда не отправляются

По умолчанию приложение никуда не отправляет данные.

- Учёта и аналитики нет. Каталог `server/` — старый локальный API, Android-приложение его не вызывает.
- Долги, платежи, цели, заметки и клиенты лежат в зашифрованной базе Room и в DataStore на устройстве.
- Синхронизация выключена, пока её не включат в настройках. Тогда обмен идёт только между устройствами в одной локальной сети, после привязки по PIN или QR, с шифрованием сессии. Служба синхронизации на устройстве запускается только в этом случае.
- Строка `web_payment_base_url` пустая, поэтому виджет не открывает внешнюю страницу оплаты.
- Ссылки вроде идей дохода или мессенджера открываются только по нажатию пользователя и не выгружают базу.

Резервная копия в Google Drive (область `drive.appdata`) в коде сохранена и сама не включается. Нужно отдельное решение: убрать её совсем или оставить выключенной опцией.
