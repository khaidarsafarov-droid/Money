# Данные для формы Data safety в Google Play

Это черновик ответов по фактическому коду приложения на момент подготовки. В консоли Play его заполняет владелец. Идентификатор приложения: `com.keystone.money`.

Приложение не подключает аналитику, рекламу и сторонние SDK сбора статистики. Поиск по проекту не находит Firebase, Crashlytics и Sentry.

## Сбор данных

Данные вводит сам человек и они остаются на телефоне, если он сам не включил резервную копию или синхронизацию с другим своим телефоном.

| Данные | Зачем | Где лежат | Обязательно |
| --- | --- | --- | --- |
| Имена людей, заметки, суммы долгов и целей, даты | Учёт личных финансов | Зашифрованная база Room/SQLCipher на телефоне | Да, иначе приложение пустое |
| Телефон и почта человека в долге | Чтобы написать напоминание, если пользователь сам выбрал отправку | Та же база | Нет |
| Контакты | Только если пользователь нажал выбор контакта и дал разрешение. Приложение читает выбранную карточку, не всю книгу | Телефон, затем поля долга | Нет |
| Календарь | Только если пользователь включил запись срока в календарь | Календарь телефона и ссылка на событие в базе | Нет |
| Фото чека или списка | Распознавание сумм на телефоне (Tesseract). Снимок хранится локально, пока его не заменят или не удалят | Файл на телефоне | Нет |
| Резервная копия | По желанию. Файл шифруется паролем и кладётся в скрытую папку приложения на Google Диске | Google Drive appData | Нет |
| Синхронизация двух телефонов | По желанию. Телефоны в одной сети обмениваются снимком данных по WebSocket. Канал шифруется ключами на устройстве | Локальная сеть, не сервер Money | Нет |
| SMS | Только если пользователь сам отправил SMS из приложения и дал разрешение. Иначе открывается обычное приложение сообщений | Оператор связи | Нет |

Деньги хранятся целыми копейками (`Long`), без дробных ошибок. Валюта по умолчанию выбирается в настройках (рубль, доллар, евро, сум, тенге и остальные валюты `java.util.Currency`). Старые записи сохраняют свой код валюты.

## Передача третьим лицам

- Google Drive и вход Google — только если пользователь сам включил копию. Токен доступа не записывается в базу.
- SMS — только по явному действию пользователя.
- Своего сервера у приложения нет. Синхронизация идёт напрямую между телефонами.

## Разрешения

| Разрешение | Зачем оставлено |
| --- | --- |
| INTERNET | Google Drive и вход Google |
| ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, CHANGE_WIFI_MULTICAST_STATE, NEARBY_WIFI_DEVICES | Поиск второго телефона в локальной сети. Флаг `neverForLocation`: геолокация не запрашивается |
| VIBRATE | Короткая отдача при действиях |
| POST_NOTIFICATIONS | Напоминания о сроках |
| RECEIVE_BOOT_COMPLETED | После перезагрузки снова поставить напоминания и обновить виджет |
| SCHEDULE_EXACT_ALARM | Напоминание в точное время |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | Экран настроек может открыть системный запрос, чтобы напоминания не откладывались. Система спрашивает человека отдельно |
| READ_CALENDAR, WRITE_CALENDAR | Запись срока в календарь, только после разрешения |
| READ_CONTACTS | Выбор контакта при создании долга, только после разрешения |
| SEND_SMS | Прямая отправка SMS, только после разрешения и явного выбора SMS |

Обычный HTTP выключен (`usesCleartextTraffic=false`). Пара телефонов говорит по `ws://` внутри локальной сети, это не веб-страницы.

## Безопасность

- База шифруется SQLCipher. Ключ случайный и запечатан в Android Keystore.
- Автоматическая резервная копия Android не забирает базу, настройки DataStore, ключ синхронизации и пароль копии. Это задано в `backup_rules.xml` и `data_extraction_rules.xml`.
- Подпись релиза берётся из переменных окружения, пароли в репозиторий не записаны.
- Удаление всех локальных данных есть в настройках копии: база, настройки, локальные снимки и расписание. Файлы, уже лежащие на Google Диске, этим действием не стираются. Их удаляют отдельно в списке копий.

## Что владелец заполняет в Play Console сам

- Вставить этот текст в Data safety.
- Выложить политику конфиденциальности по постоянному адресу и вставить ссылку.
- Загрузить подпись релиза. Её нет в репозитории.
- Если приложение уже опубликовано как `com.example.money`, новый идентификатор `com.keystone.money` — это другое приложение. Старые установки и их база не переедут сами.
