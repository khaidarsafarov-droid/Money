# Roadmap: психология финансов (Project Money)

Стратегия: отойти от «учёта цифр» к снижению стресса, надежде и микропобедам.
Стек: **Android (Kotlin Compose + Room)**, **Web (React)**, **`packages/shared`**.

---

## Фаза 1 — Просмотр будущего + Генератор побед ✅

**Цель:** дата свободы от долгов и вехи на карточках.

| Компонент | Android | Web | Shared |
|-----------|---------|-----|--------|
| Движок прогноза | `DebtFreedomEngine.kt` | `debtFreedomEngine.ts` | `debtFreedomEngine.ts` |
| Вкладка «Свобода» | `DebtFreedomTab.kt` | `FreedomForecastCard.tsx` | — |
| Вехи на карточке | `DebtorListItem.kt` | `DebtCard.tsx` | `computeDebtMilestones` |
| Ускорить платёж | `DebtPaymentDialog` + prefill | `PaymentModal` prefill | `suggestAcceleratePaymentCents` |

**Офлайн:** полностью локально, без API.

## Фаза 2 — Безопасный сейф ✅

**Цель:** доверие и отсутствие стыда.

- [x] `MoneyPreferencesStore`: `privacy_hide_amounts`, `privacy_hide_on_widget`
- [x] Web: зеркало в `localStorage` (`appPsychologyStorage.ts`)
- [x] Маскирование сумм в списках и виджете (`•••`)
- [x] Нейтральные Snackbar/toast при оплате (`msg_payment_neutral` / «Операция сохранена»)
- [x] Экран настроек приватности (Android + web `PsychologySettingsPanel`)

**Офлайн:** да.

---

## Фаза 3 — Умный собеседник (шаблоны) ✅

**Цель:** интерпретация данных человеческим языком без LLM.

- [x] Bottom sheet «Советник» на экране долгов (Android + web)
- [x] Шаблоны: «какой долг закрыть первым», «что если +$50», «мотивация»
- [x] Расширение `VoiceReportComposer` советами по долгам
- [x] История диалога в DataStore / localStorage

**Офлайн:** да (шаблоны). LLM — отдельная фаза 3b.

---

## Фаза 4 — Геймификация ✅

**Цель:** streaks, значки, общий прогресс.

- [x] Состояние геймификации в DataStore + web localStorage
- [x] Streak: последовательные платежи до срока
- [x] Значки: «Первый шаг», «Полпути», «Свобода», «Серия ×3»
- [x] Виджет: streak / последняя победа
- [x] `GamificationBanner` на Android и web

**Офлайн:** да.

---

## Фаза 5 — Автопилот ✅

**Цель:** микроплатежи без усилий.

- [x] Настройки автопилота: ежедневная сумма, стратегия (снежный ком / лавина)
- [x] `applyMicroPaymentSync()` → целевой долг по стратегии
- [x] WorkManager: напоминание «внести микроплатёж сегодня»
- [x] Web: кнопка «Внести сейчас» + настройки в панели
- [ ] *(Позже)* округление покупок — только с банковским API

**Офлайн:** ручные микроплатежи — да; банк — нет.
