# Roadmap: психология финансов (Project Money)

Стратегия: отойти от «учёта цифр» к снижению стресса, надежде и микропобедам.
Стек: **Android (Kotlin Compose + Room)**, **Web (React)**, **`packages/shared`**.

---

## Фаза 1 — Просмотр будущего + Генератор побед ✅ (текущий PR)

**Цель:** дата свободы от долгов и вехи на карточках.

| Компонент | Android | Web | Shared |
|-----------|---------|-----|--------|
| Движок прогноза | `DebtFreedomEngine.kt` | `debtFreedomEngine.ts` | `debtFreedomEngine.ts` |
| Вкладка «Свобода» | `DebtFreedomTab.kt` | `FreedomForecastCard.tsx` | — |
| Вехи на карточке | `DebtorListItem.kt` | `DebtCard.tsx` | `computeDebtMilestones` |
| Ускорить платёж | `DebtPaymentDialog` + prefill | `PaymentModal` prefill | `suggestAcceleratePaymentCents` |

**Офлайн:** полностью локально, без API.

---

## Фаза 2 — Безопасный сейф

**Цель:** доверие и отсутствие стыда.

- [ ] `MoneyPreferencesStore`: `privacy_hide_amounts`, `privacy_hide_on_widget`
- [ ] Web: зеркало в `localStorage`
- [ ] Маскирование сумм в списках и виджете (`•••`)
- [ ] Нейтральные Snackbar/toast при оплате (без осуждающих формулировок)
- [ ] Экран настроек приватности (Android + web)

**Офлайн:** да.

**PR:** `cursor/privacy-safe-vault-4958`

---

## Фаза 3 — Умный собеседник (шаблоны)

**Цель:** интерпретация данных человеческим языком без LLM.

- [ ] Bottom sheet «Советник» на экране долгов
- [ ] Шаблоны: «какой долг закрыть первым», «что если +$50», «мотивация»
- [ ] Расширение `VoiceReportComposer` советами по долгам
- [ ] История диалога в DataStore (локально)

**Офлайн:** да (шаблоны). LLM — отдельная фаза 3b.

**PR:** `cursor/debt-advisor-templates-4958`

---

## Фаза 4 — Геймификация

**Цель:** streaks, значки, общий прогресс.

- [ ] Таблица/поле `milestones_unlocked` (Room + web state)
- [ ] Streak: последовательные платежи до срока
- [ ] Значки: «Первый шаг», «Полпути», «Свобода»
- [ ] Виджет: streak / последняя победа

**Офлайн:** да.

**PR:** `cursor/debt-gamification-4958`

---

## Фаза 5 — Автопилот

**Цель:** микроплатежи без усилий.

- [ ] Настройки автопилота: ежедневная сумма, стратегия (снежный ком / лавина)
- [ ] `applyMicroPayment()` → целевой долг по стратегии
- [ ] WorkManager: напоминание «внести $3 сегодня»
- [ ] *(Позже)* округление покупок — только с банковским API

**Офлайн:** ручные микроплатежи — да; банк — нет.

**PR:** `cursor/debt-autopilot-4958`

---

## Фаза 3b (опционально) — AI-коуч

- OpenAI / локальная LLM
- Требует API-ключ, политику приватности
- Не блокирует фазы 1–5

## Как вести работу

1. Одна фаза = одна ветка `cursor/<name>-4958` + draft PR в `master`.
2. Логика расчётов — сначала `packages/shared` + тесты, затем Kotlin-зеркало.
3. UI — Milk-Rich палитра (cream / gold / green / red), без синего/фиолетового из RN-прототипа.
