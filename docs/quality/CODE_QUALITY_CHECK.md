## Исправлено

1. **Синхронизация снимка.** Платёж, чей долг отсутствует в снимке, пропускался при вставке (долг удаляется каскадом), а затем `buildDebtPaymentSyncIdMap` бросал `error(...)` и откатывал весь `apply()`. Такие платежи больше не входят в keep-set и не обязательны для карты id. Неизвестный `kind` транзакции больше не считается переводом.
2. **`!!` в продовом коде.** Убраны в `AddDebtorDialog`, `GoalFormDialog`, `OnboardingScreen`, `DebtorRepositoryImpl` (`paymentId`), `DeviceIdProvider`, `DebtCalendarSyncService`. В `app/src/main` оператора `!!` не осталось.
3. **Локализация форм.** `InputValidators` возвращает id строковых ресурсов. Диалоги перевода и расхода (`AddBudgetDialogs`) больше не содержат захардкоженный русский текст.

Пункты чеклиста 51, 52, 65–70 отмечены `[x]`.

## Что осталось

- **Английская локаль неполная.** В `values/strings.xml` 579 ключей, в `values-en/strings.xml` 371. Недостающие 208 ключей (онбординг, Goal Hub, страхи, психотип, календарь, еженедельный чек-ин и др.) на английском откатываются к русскому тексту из `values/`.
- **`HomeScreen.kt` — 1533 строки.** Экран совмещает список, drawer, диалоги и вкладки. Это главный кандидат на разбиение; в этой проверке файл не резался, чтобы не сломать навигацию без UI-прогона.
- **Пустое состояние вкладки «Свобода».** `DebtFreedomTab` при отсутствии долгов ведёт в Goal Hub и не показывает CTA «Идеи дохода» (пункт чеклиста 13 всё ещё `[~]`). Идеи дохода есть в ряду инструментов на главной и в планшете.
- **Онбординг не называет Советник, Автопилот и Goal Hub** (пункты 18–20). Текст приветствия про путь к свободе и психотип, без этих названий.
- **Предупреждения компилятора, не из этого диффа:** reified intersection в миграциях Room, устаревшие `TabRow`, `Locale(String, String)`, NSD `resolveService`.

Пункты чеклиста 8, 11, 13–20 и блоки QA по `DebtAutopilotEngine` / `DebtGamificationEngine` (603–634) оставлены `[~]`: движки не рисуют UI, а навигационные пункты либо уже есть в другом месте, либо в коде не найдены.
